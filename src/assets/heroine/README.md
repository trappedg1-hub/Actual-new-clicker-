# HEROINE-01 assets

The runtime uses the approved BLOCK 1 production assets from `art-studio/production/BLOCK-1-FINISH-CHARACTER-ASSETS/BUILD-v01/`: 20 independent RGBA slots, 10 approved E2-V2 full-frame state references, 4 approved transparent expression overlays, 26 HZ masks and a hidden technical underlay. Vite imports them with `?url`; nothing is copied, regenerated or atlased. Runtime textures are compact, alpha-padded copies of each approved slot; no full-canvas static sprite covers the animated rig. The 10 full-frame states contain their original background, so `ProductionHeroineRig` applies a rounded face mask at runtime and hides slots 13–16; only approved face pixels reach the transparent character. No new expression or anatomy art is generated.

`src/heroine/rig/LayeredHeroineRig.ts` is the old technical vector placeholder, retained only because existing Node regression tests import it. It is no longer used by `MainScene`. No AI-generated artwork or new expressions are present.
