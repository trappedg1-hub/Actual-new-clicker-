# Отклонённый вариант маски (сохранён намеренно)

Первый технический подход к пилоту `eye_l_closed-B`: маска пропускала
**только тёмные штрихи** утверждённого элемента, а вся кожа бралась из
вручную восстановленной чистой базы.

Защитные зоны в этом варианте тоже не повреждались (`maxDiff = 0` по всем
семи зонам), но на лице ×4 и на глазе ×8 была видна **плоская
прямоугольная заплатка кожи** с жёсткой вертикальной границей у пряди
волос и жёсткой горизонтальной границей под бровью.

Поэтому вариант **не принят как результат пилота**. Вместо него:

1. `EYE_POLY` переделан под диагональный край пряди (не прямоугольник);
2. кожа восстановлена интерполяцией по 13 реальным образцам, а не плоским
   градиентом;
3. итоговая маска `02-mask-eye_l_closed-B.png` — мягкая гибридная линза:
   штрихи непрозрачны, кожа элемента на 55 % смешана с чистой базой.

Файлы здесь оставлены, чтобы дефект можно было увидеть, а не чтобы его
скрыть. Они не являются approve-материалом и не используются в
`03-overlay-full.png`.

Генеративный ИИ, inpainting и generative fill не применялись ни в этом,
ни в принятом варианте.
