## 1. Короткий итог (без прикрас)

Сделаны 20 **контурных RGBA-слоёв** на общем холсте 848×1264: прямоугольных окон больше нет,
альфа повторяет форму детали, RGB побайтно скопирован из исходного кадра.
Композит всех 20 слоёв собирает персонажа **без дыр и без пересвета** — визуально и по RGB
совпадает с вырезкой этапа 04.

**Но независимыми в полном смысле эти слои пока НЕ являются.** Исходник — один уже
скомпонованный кадр: у перекрытых деталей не существует пикселей «под» ними. E1 честно
показывает эти прозрачные подложки, а не маскирует их. При сдвиге слоёв открывается
**2.4–10.0 %** площади силуэта (замер ниже). Закрыть это может только E2 — дорисовка скрытых
зон, на которую у меня нет разрешения.

Это ровно тот случай, который описан в твоём пункте 6: исходный кадр не позволяет качественно
отделить конкретный слой. Список — в §6.

## 2. Что сделано

| Шаг | Результат |
|---|---|
| Изучены цветовые кластеры кадра | 8 классов: `hair`, `skin`, `skin_hl`, `white`, `navy`, `stocking`, `eye_green`, `dark_line` + `other` |
| Заданы анатомические полигоны для 20 зон | форма челюсти, V воротника, трапеция юбки, овалы глаз/рта, массы волос |
| Построена контурная альфа | `силуэт ∩ зона ∩ (класс не чужой)` + сглаживание внешнего контура 1 px |
| Назначение пикселей | **winner-takes-all по z-order**: каждый пиксель ровно в одном слое |
| Fallback | пиксели вне полигонов (кончики пальцев, тонкие пряди, края обуви) отнесены к ближайшей зоне |
| Слои | 20 PNG, полный холст 848×1264, RGBA, `layers/` |
| Машиночитаемые данные | `layer-map.json`, `e1-motion-gaps.json` |
| Воспроизводимые исходники | `build_layers.py`, `check_motion_gaps.py` |
| Технические превью | `preview/E1-composite.png`, `E1-layers-contact.png`, `E1-motion-gaps.png` |

**Ключевые технические решения (и почему):**

1. **Чистый RGB-классификатор отброшен.** Тёмно-синяя юбка/воротник и тёмные тени волос
   объективно неразличимы (на этапе 04 замерено L1 25–37 против фона); тень на коже и чулок
   тоже. Поэтому вычитаются **только достоверно чужие** классы, а всё неопределённое остаётся
   в своей зоне. Иначе теряются части персонажа.
2. **Перекрытие устранено по z-order.** Первая версия давала 42 % пикселей сразу в нескольких
   слоях и «пересвечивала» белую блузку (RMSE 0.856). Назначение по убыванию z убрало
   дублирование: `overlap = 0`, композит стал равен исходнику.
3. **Сглаживание только по внешнему контуру.** Размытие внутренних швов создавало
   полупрозрачные двойные линии. Теперь внутренние стыки полностью непрозрачные.
4. **Найден и исправлен реальный баг потери деталей:** 15 918 пикселей, назначенных fallback'ом,
   лежали вне полигонов и не записывались в PNG, хотя JSON показывал покрытие 100 %.
   После исправления `rest gaps = 0`.

## 4. Тест движения: количественно, почему нужен E2

`check_motion_gaps.py` — **translation proxy**, не поворот и не реальный кадр анимации.
Каждый слой сдвигается на небольшой вектор, аппроксимирующий амплитуды из
`ANIMATION-SPEC.md` §5, и считаются полностью прозрачные пиксели силуэта.

| Сдвиг | dx | dy | Открылось px | Доля |
|---|---:|---:|---:|---:|
| покой | 0 | 0 | **0** | 0.0000 |
| волосы ±10° (proxy) | ±12 | 0 | 29 019 | 0.1004 |
| руки ±25° (proxy) | ±10 | ±6 | 25 212 | 0.0872 |
| голова ±12° (proxy) | ±6 | ±8 | 17 549 | 0.0607 |
| дыхание ±6° (proxy) | 0 | ±5 | 6 834 | 0.0236 |

Красная карта: `preview/E1-motion-gaps.png`. Видно, что открываются контуры волос,
пальцы, линия подола и внешние контуры ног — ровно те скрытые зоны, что перечислены в
`PLAN.md` §2. **Вывод:** плавная анимация на текущих слоях невозможна; E2 обязателен.

## 5. Что означает «независимый слой» после E1

Слои **контурные** (не прямоугольники), **непересекающиеся**, с корректными пивотами и
z-order, но с `independent: false` в `layer-map.json`. Причина проста: в одном кадре нет
пикселей под перекрытиями, а дорисовывать их без разрешения нельзя. Изолированный слой
поэтому содержит прозрачные подложки там, где в композите работает соседний слой.
На тёмном фоне контактного листа (`preview/E1-layers-contact.png`) это выглядит как
«рваные» места — это **не дефект сегментации**, а честно показанная граница перекрытия.

Слои хранятся на общем холсте 848×1264, чтобы `anchor = pivot / size` и z-order работали
без пересчёта; `tightRect` в `layer-map.json` готов для будущего атласа (атлас — отдельный гейт).

Также остаются 4 отсутствующих состояния: `eye_l_closed`, `eye_r_closed`, `mouth_open`,
`mouth_smile`. В E1 они **не создавались** — для них нужен отдельный арт-проход (E3).

## 6. Слоты, которые исходный кадр НЕ позволяет отделить качественно (твой пункт 6)

Перечисляю прямо, без сглаживания формулировок. Полный текст по каждому слоту — в
`layer-map.json → slots[].knownLimit`.

**Критичные (блокируют анимацию до E2):**

| Слоты | Проблема |
|---|---|
| `head` z13 | В базе головы теперь прозрачные зоны на месте глаз и рта (их забрали z14–16). Это технически «чистая база», но с дырами, а не с восстановленной кожей. Моргание видимостью заработает только после E2/E3. |
| `arm_l/r` z6–7 | Пряди волос лежат поверх предплечья и кисти; пикселей кожи под ними не существует. «Колпак» плеча не нарисован — при ±25° откроется дыра. |
| `hair_back_01/02` z1–2 | Задние волосы запечены вместе с плечами, руками и воротником; тёмные тени волос RGB-неотличимы от тёмно-синей ткани. Разделить без дорисовки нельзя. |
| `outfit_collar` z9 | Воротник запечен на коже V-выреза и блузке. При наклоне головы ±12° (воротник НЕ наследует голову) откроется шея/ключицы, которых в кадре нет. |
| `outfit_skirt_01/02` z11–12 | Граница между ними — условная горизонталь, а не анатомия. При инерции с задержкой 80–150 мс стык раскроется; под подолом нет бёдер и внутренних складок. |
| `torso` z5 | Всего 3 750 px (кожа декольте/шеи): торс объективно закрыт одеждой. Для «внутреннего» дыхания ±6° нужна подложка — без E2 слой почти пустой. |

**Существенные:**

| Слоты | Проблема |
|---|---|
| `eye_l_open` z14 | Лицевая прядь пересекает левый глаз — глаз не отделяется полностью. |
| `eye_r_open` z15 | Кроп почти касается уха; закрытого состояния нет. |
| `mouth_neutral` z16 | Существует только нейтральный рот. |
| `hair_side_l/r` z17–18 | Пряди пересекают бровь/щёку/глаз; лица под ними нет. |
| `hair_front_01/02` z19–20 | Чёлка запечена на лбу; линия роста волос под ней отсутствует, разделение между 01/02 условное. |
| `leg_l/r` z3–4 | Бедро, чулок и обувь — единая запечённая масса; отдельного якоря стопы нет (см. также вопрос §2.6 плана). |
| `outfit_blouse` z8 | Делит тёмно-синие полосы рукавов с воротником и лежит под лентой. |
| `outfit_ribbon` z10 | Узел запечен на блузке, подложки нет. |
| `hair_back_02` z2 | Верхняя масса перекрывает плечи и воротник. |

**Отдельно:** публичные GitHub-проекты по анимации остаются только техническими референсами
и не являются твоими репозиториями или каноном. Vercel не использовался.
