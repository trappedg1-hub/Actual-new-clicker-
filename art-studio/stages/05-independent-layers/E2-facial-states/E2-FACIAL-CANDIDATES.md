## 3. Технический метод (важно для проверки)

1. AI возвращает **непрозрачный** RGB-патч. Модель не умеет отдать настоящий альфа-канал:
   первый пилот нарисовал «шахматку» прямо в RGB (`pilot-eye-l-closed-v1`, отклонён).
   Поэтому прозрачность сделана **технически**, а не генерацией.
2. Патч приводится к 4:3 обрезкой по центру (без искажения пропорций) и масштабируется
   в 80×60 — ровно тот контекстный кроп, который подавался референсом.
3. Регистрация: сдвиг патча измеряется минимизацией RGB-ошибки по **окружающим** пикселям
   (волосы, бровь, кожа, блик носа), сама фича из сравнения исключена.
4. Патч кладётся на холст 848×1264 и обрезается **сплошным эллипсом зоны** из
   `layer-map.json` (`zonePolygon` z14/z15/z16). Rect и pivot совпадают со слотом.
   Центры: (397,162), (457,162), (422,199).

### Отклонённый тупик (не скрываю)

Сначала альфа копировалась **байт-в-байт из слоёв E1** z14/z15/z16 (1224 / 1537 / 1362 px).
Оказалось, что это не сплошной эллипс, а «чернильная» маска **по форме открытого глаза**:
сквозь её дыры на композите просвечивала исходная зелёная радужка — получался
полузакрытый глаз. Метод отброшен, заменён сплошным эллипсом зоны. Оба варианта
задокументированы в `E2-alignment.json` (`deadEnd`).

**Вывод для будущей интеграции:** у закрытого состояния сплошной след, у открытого —
разреженный «чернильный». Это асимметрия, её надо учесть при E3. Полноценное переключение
видимостью всё равно требует **чистой базы лица** (скрытая зона, `head` z13 до сих пор
содержит запечённые открытые глаза и нейтральный рот) — см. §6.

## 4. Оценка каждого кандидата

`сдвиг` = смещение центроида тёмных линий относительно оригинала, пиксели исходного кадра.
`шов` = средняя разница RGB в кольце 0.82–0.98 радиуса эллипса (меньше = лучше).
`annulus` = ошибка совмещения окружающих пикселей (меньше = лучше).

2. **Прозрачность — техническая.** Модель физически не отдаёт альфа; изолированность

3. **Манера.** Элементы сделаны в манере кадра `IMG_4038` (он же геометрический источник E1),
   чтобы не было шва с окружающими пикселями. Приведение финального рендера к канону
   `IMG_4036`/`IMG_4037` — это `E4 05.4-render-canon`, не выполнялось. Вариант B — лишь

5. **B-варианты трёх состояний рта отсутствуют** из-за лимита 10 генераций на ход.
6. **Не изменены:** 3 оригинальных WebP, `work-cutout.png`, все 20 слоёв E1, `layer-map.json`,
